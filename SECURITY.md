# Security Policy

## Reporting a vulnerability

Please report security issues privately to Zain Ul Abedin (https://github.com/zainAwan9175).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/zainAwan9175/resend-api-sdk/issues

## Scope

This policy applies to the generated Zain Ul Abedin SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Resend public API, generated by
Zain Ul Abedin. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
